# 隐私政策

[English](PRIVACY.en.md) · [简体中文](PRIVACY.zh-CN.md)

0.0.0.6 · 2026-11-03

扩展保存账号名称、密钥、算法、位数、周期与顺序。验证码与二维码均在设备上处理，不包含统计分析、广告、跟踪或上传至开发者服务器的逻辑。

Chrome sync 可能根据浏览器设置通过浏览器账号同步配置，数据并非保证只留在本设备。网页预览使用独立的 localStorage。

storage 用于保存配置；contextMenus 提供账号选择；activeTab 与 scripting 仅在用户主动填充时写入验证码。扩展不会持续采集网页内容，也不会为生成验证码读取浏览历史。

备份与二维码包含未加密密钥，导入在本机校验。可在扩展中删除配置，已导出文件需自行删除。卸载可能清除扩展数据，请提前备份。

升级存储时可能临时在本机保存未加密的恢复记录。验证成功后删除；失败或结果不一致时保留以供恢复，该副本不会发送给开发者。

隐私问题请通过项目 Issues 反馈。 [GitHub Issues](https://github.com/ydq/auto-mfa/issues).
